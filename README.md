A single line of earned pride — pride that comes from real work, not vanity. One concrete image: sawdust on the hands, a chair built by hand, and a father's weight held without a single creak. The proof of the work is the silence of the thing made well.

## Run it

```bash
python3 main.py
```

The program prints exactly one line to stdout and exits 0. It is fully deterministic — no randomness, no time, no environment dependence — so every run produces byte-identical output.
